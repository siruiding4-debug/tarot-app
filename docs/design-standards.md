# 塔罗牌隔空手势抽取网站 - 设计规范文档

## 视觉风格定位
关键词：**暗黑神秘**、**简约魔法**、**仪式感**
- 不是哥特式恐怖，不是花哨非主流
- 是克制的、优雅的、有呼吸感的黑暗
- 灵感来源：星空、水晶、月光、古老羊皮卷

## 配色方案

### 主色调
```css
--bg-deep: #0a0a0f;        /* 最深背景 */
--bg-purple: #120a1e;      /* 深紫黑背景 */
--bg-card: rgba(20, 15, 35, 0.6); /* 卡片背景（毛玻璃）*/
```

### 强调色
```css
--gold-dark: #c9a84c;      /* 暗金 - 边框、图标 */
--violet: #7b4fa0;         /* 紫罗兰 - 次要强调 */
--blue-deep: #1a3a5c;      /* 深蓝 - 辅助 */
```

### 发光色（用于发光效果）
```css
--glow-gold: #f0d060;      /* 暖金发光 */
--glow-purple: #a855f7;    /* 魔法紫发光 */
--glow-blue: #6366f1;      /* 靛蓝发光 */
```

### 文字色
```css
--text-gold: #e8d5a3;      /* 淡金文字 */
--text-gray: #c4c4c4;      /* 灰白正文 */
--text-dim: #6b6b7b;       /* 暗淡辅助文字 */
```

## 字体规范

### 标题字体（衬线）
- 字体族：Georgia, 'Times New Roman', serif
- 使用场景：页面主标题、牌名、阶段标题
- 特点：有历史感、仪式感

### 正文字体（无衬线）
- 字体族：'Inter', system-ui, -apple-system, sans-serif
- 使用场景：正文、解读文字、按钮、UI标签
- 特点：清晰易读

## 组件设计规范

### 卡片 (Card)
- 背景：半透明深色 + backdrop-blur
- 边框：1px solid，带发光效果
- 圆角：12px
- 悬停：边框发光增强
- 阴影：box-shadow 使用强调色

### 按钮 (Button)
- 主按钮：暗金背景，深色文字
- 次按钮：透明背景，发光边框
- 圆角：8px
- 悬停：scale(1.02) + 发光增强

### 输入框 (Input)
- 背景：半透明深色
- 边框：底部分割线，聚焦时发光
- 文字色：淡金

### 模态框/弹窗
- 背景：深色毛玻璃
- 边框：细线发光
- 入场动画：fade + scale

## 动画规范

### 入场动画
- 页面切换：fade in (0.5s) + 轻微上移 (20px → 0)
- 卡片出现：scale (0.8 → 1) + fade (0.4s)
- 文字出现：fade in (0.3s)，逐行延迟

### 交互反馈
- 悬停：scale(1.02)，边框发光增强
- 点击：scale(0.98)，短暂反馈
- 选中：外发光 pulse

### 粒子效果
- 漂浮光点：缓慢上浮 + 透明度波动
- 选中爆发：从选中点向外扩散金色粒子
- 能量场：旋转光环，透明度呼吸

### 牌面动画
- 洗牌：牌面交错、旋转、位置随机化
- 翻牌：3D rotateY 动画 (0 → 180deg)
- 扇形展开：牌面依次旋转排列

## 布局规范

### 桌面端 (≥1024px)
- 内容最大宽度：800px，居中
- 摄像头小窗：右下角，200x150px
- 扇形牌面：水平展开

### 响应式断点
- sm: 640px
- md: 768px
- lg: 1024px
- xl: 1280px

## 神秘元素设计

### 几何符号
- 六芒星（✡）：用于加载、背景装饰
- 眼睛（👁）：用于关键交互点
- 月亮（🌙）：阶段指示器
- 曼陀罗花纹：背景装饰

### 装饰线
- 水平分割线：两端渐隐的金色细线
- 角落装饰：L形金色边框装饰

# 塔罗牌隔空手势抽取网站 - 开发需求文档

## 项目概述
构建一个暗黑神秘风格的塔罗牌抽取网站，用户通过**隔空手势**（摄像头识别）完成洗牌、切牌、抽牌、翻牌等仪式流程。

## 核心功能需求

### F1: 塔罗牌仪式流程
模拟实体塔罗牌抽取的完整流程：
1. **准备阶段**：能量场构建，冥想引导，环境净化
2. **洗牌阶段**：通过手势左右滑动完成洗牌
3. **切牌阶段**：通过握拳手势完成切牌
4. **抽牌阶段**：通过食指悬停选择卡牌
5. **翻牌阶段**：通过张开手掌手势翻牌
6. **解读阶段**：按牌阵位置展示解读结果

### F2: 牌阵支持
- 单张牌：每日指引
- 三牌阵：过去/现在/未来
- 圣三角：本质/阻碍/建议
- 凯尔特十字：十张牌全面解读

### F3: 逆位支持
- 随机出现正位/逆位
- 正逆位含义不同

### F4: 问题输入
- 抽牌前可输入问题
- 也可跳过，默认为"宇宙的指引"

### F5: 历史记录
- localStorage 保存每次抽牌结果
- 可回顾、删除历史记录

### F6: 音频
- 背景氛围音乐
- 操作音效（洗牌、切牌、翻牌、揭示）

### F7: 隐私保护
- 无需登录注册
- 所有数据仅存本地浏览器
- 摄像头数据仅在本地处理，不上传

## 非功能需求

### NF1: 性能
- 手势识别延迟 < 100ms
- 页面加载时间 < 3s

### NF2: 兼容性
- 支持 Chrome、Edge 浏览器（MediaPipe 兼容性最佳）
- 桌面端优先（需要摄像头）

### NF3: 可用性
- 手势指引清晰
- 错误状态友好提示（摄像头未授权等）

## 版本规划

### v1.0 - MVP
- 完整仪式流程
- 四种牌阵
- 手势识别
- 基础解读
- 历史记录
- 暗黑主题

### v1.1 - 增强
- 更多牌阵
- AI 解读（可选）
- 音效增强
- 移动端适配
